# 🎮 Enable GitHub Pages - One Click Required

Your Neon Ruin game is ready to publish! All files are deployed to the `main` branch.

## ⚡ Quick Start (30 seconds)

1. **Open Settings**: https://github.com/davidepiazza-afl/neon-ruin/settings/pages

2. **Configure Source**:
   - Find "Build and deployment" section
   - Under "Source", select: **GitHub Actions**
   - Click **Save** (if needed)

3. **Done!** Your game will be live at:
   ### 🌐 https://davidepiazza-afl.github.io/neon-ruin/

## What Happens Next?

- The GitHub Actions workflow will run automatically (takes ~1 minute)
- Check progress: https://github.com/davidepiazza-afl/neon-ruin/actions
- Once complete, the game is live and playable!

## Alternative: Deploy from Branch

If you prefer the classic method:

1. Go to: https://github.com/davidepiazza-afl/neon-ruin/settings/pages
2. Under "Source", select: **Deploy from a branch**
3. Choose branch: **main** 
4. Choose folder: **/ (root)**
5. Click **Save**

---

**Note**: This manual step is required due to GitHub security policies. The API/CLI cannot enable Pages automatically, even with admin tokens. This is a one-time setup!
